# SourceCode

This folder is the base folder for the sourcecode of OpenShoeDesigner. This C++ code is completely in this folder and the sub-folders.

## Sub-Folder:

### 3D
The 3D function using OpenGL / [Glad 2](https://gen.glad.sh/).

### gui

The user interface. It is implemented using [wxWidgets](https://wxwidgets.org/). The file gui.cpp and gui.h are autogenerated by [wxFormbuilder](https://github.com/wxFormBuilder/wxFormBuilder) from the openshoedesigner.fbp file.

### math

Mathematical functions. Some accelerated using [Eigen](https://libeigen.gitlab.io/).

### project

Classes to hold all the data in the project and transform the data.

### system

Functions close the the OS. Contains also read/write functions for INI and JSON files and an interface to 6-DOF controllers.

## Building

Run in the parent folder to this folder:

```shell
cmake -B build
cmake --build build -j
```
